# 福寿螺卵识别与云台系统验收标准

本文档用于训练、评测、部署和实机复核。所有指标必须注明数据来源；PC 合成压力测试、MaixCAM 实机采集和无标签历史截图不能混写。

## 1. 数据分层

| 层级 | 用途 | 是否可作为最终召回率 |
| --- | --- | --- |
| 训练集 | 训练和微调 | 否 |
| 独立 MaixCAM 标注集 | 真实相机、真实光照和显示链路验证 | 是 |
| 物理采集留出集 | 不进入训练的另一批相机采集 | 是，按帧级或框级分别报告 |
| PPT/合成压力集 | 尺度、运动、亮度、组合场景压力测试 | 只能作为压力指标 |
| 历史原始截图 | 观察域差异和连续响应 | 否，除非逐帧补齐标注 |

同一物理源图的亮度、位置和颜色变体必须放在同一来源组，不能把变体拆到训练和验证两侧。每次评测保存数据清单、源图哈希、模型 SHA256、参数和脚本版本。

## 2. 检测验收

### 2.1 独立 MaixCAM 标注集

- 标注框召回率：IoU >= 0.5，目标 >= 92%。
- 标注负样本帧误检率：目标 <= 1%。
- 正样本来源组的“任一变体命中率”和“全部变体命中率”必须同时报告。
- 正样本若只标注了一个框，不得把其他未标注目标当成确定的误检；这类 precision 只能标为 `proxy`。

### 2.2 压力集

- 静止、运动、轻微抖动、亮度变化、距离变化和多目标组合分别统计。
- 小目标压力集单独报告帧级命中率，不冒充框级召回率。
- 负样本应包含红色物体、粉色物体、花朵、贴纸、塑料、反光、锈斑、文字和复杂背景。

## 3. 历史实机截图审计

历史截图大多是相机对着显示器的域适配材料。脚本只能报告检测响应率、连续帧检测分歧率、检测后掉检率和推理时延，不能把“有框”直接叫作召回率。

连续性只允许使用 `once_<设备帧号>` 的相邻帧，并在设备帧号跳跃或画面发生明显切换时断开序列。不同采集会话、重复截图和带检测框的叠加图必须单独标注。

## 4. 性能验收

- 采集循环、检测刷新、网页视频流和舵机控制分别计时。
- 报告 `loop_fps`、`detect_hz`、`stream_fps`、端到端控制延迟 P95，不用一个 FPS 代替全部性能。
- 固定尺寸导出使用 `320x224`；Ultralytics 训练阶段以长边 320 的矩形 batch 为准，不能声称训练阶段使用了真正的非方形输入。
- 网络视频流必须丢弃旧帧，队列最多保留最新一帧。

## 5. 云台验收

- 两轴使用同一段归一化直线插值轨迹，避免先动一个轴再动另一个轴。
- 左右限幅 `60..120°`，俯仰限幅 `80..120°`，默认 `90°`。
- 不允许目标短暂丢失后自动跳到另一个目标；人工选定目标后，锁定期间只允许在锁定框附近保持或逐步修正。
- 记录目标中心、云台角度、PWM 时间戳、检测置信度和锁定状态，验收以轨迹数据为准。

### 5.1 选定目标状态机

1. `select/confirming`：手机点击一个已经检测出的绿色框后，只保存该目标 ID、点击时的框尺寸和一次保守角度估计；此阶段云台不因单帧结果移动。
2. `selected/stable`：同一锁定 ID 连续 4 次有效观测，且中心位移和框尺寸变化在门限内，才允许闭环跟踪。
3. `manual/approach_hold`：连续 8 次检测仍不能确认稳定锁定时，只按点击时的保守角度缓慢趋近，然后冻结，交给方向键微调；不得寻找或接管其他目标。
4. 稳定锁定后短时漏检只保持原 ID 的预测；达到丢失门限后完成最后可靠角度计划并冻结，同样不得切换目标。
5. 程序退出时保持当前舵机位置后关闭 PWM，不自动回中或扫动。

## 6. 激光安全

- 辅助瞄准激光默认关闭。
- 视野内约 2 秒没有任何有效福寿螺卵目标时关闭辅助激光。
- 摄像头、模型、通信或程序异常时关闭辅助激光。
- 高功率激光或消杀执行器不由识别程序自动触发，必须由人工确认。

## 7. 当前审核结论

### 2026-07-19 v26 更新

v26 已取代 v6 成为发布主干。它在独立相机标注集上达到 94.29% 框召回，在同口径 1000 帧压力集上达到 86.73% 召回，并把 1378 张外部负样本的图像误检率降至 0.65%。全画面发现使用 0.35 高阈值；人工点选后，0.10 到 0.35 的弱检测只能作为锁定轨迹的关联测量，不能生成轨迹或切换目标。v27 因独立相机召回和外部负样本表现退化而淘汰。最终户外实机视频指标仍需在设备重新接入后补测，PC 压力结果不得冒充实机验收。

截至 2026-07-19，v6 仍是部署基线；v13 是最新本地候选。v13 改善了跨光照压力召回和历史帧连续响应，但外部困难负样本误检率仍为 1.02%，尚未达到 `<= 1/1000` 的目标，因此只能进入下一轮实机量化验证，不能直接替换 v6。v12、v14、v15 已分别因过量误检或独立召回退化淘汰。
