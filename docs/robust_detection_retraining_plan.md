# 福寿螺卵真实环境鲁棒检测重训方案

## 问题判断

当前部署权重在仓库 test 上达到约 `P=0.906 / R=0.947 / mAP50=0.969`，但 MaixCam 实拍中对偏角、浅色、暗光和屏幕摩尔纹明显掉点。这是训练/测试域与 GC4653 实际成像域不一致，不是单纯调低置信度能解决的问题。

现有 v8 数据集共有 3470 张图，其中训练集 2939 张，只有 1060 张带正目标，1879 张是负样本；独立 test 只有 50 张正图。后续不再把原 test 指标当作最终验收。

## 方法评判

| 方法 | 预期收益 | MaixCam 代价 | 决策 |
|---|---:|---:|---|
| MaixCam 真实域采集和少量精标 | 最高，直接覆盖传感器、镜头、曝光和摩尔纹 | 仅增加训练工作 | 采用 |
| 困难负样本闭环挖掘 | 显著降低粉色物体、红点和反光误检 | 无推理代价 | 采用 |
| 受控光照/颜色/模糊/尺度增强 | 提升浅色、暗光、偏角和抖动鲁棒性 | 无推理代价 | 采用 |
| 目标感知混合/粘贴 | 保留卵团纹理并扩展背景 | 无推理代价 | 小比例采用 |
| Mosaic + 多尺度训练 | 改善远处小目标 | 无推理代价 | 采用，最后若干 epoch 关闭 |
| SAHI 切片推理 | 小目标召回可能提高 | 多次 NPU 推理，实时性下降 | 只用于离线诊断/训练裁片 |
| 更大的模型 | 可能提高上限 | INT8 后速度和内存风险明显 | 只比较 nano 级候选 |
| 只降低置信度或只靠颜色 | 表面召回上升 | 大量误检、红点自锁 | 不采用 |

依据：

- [Ultralytics 数据增强说明](https://docs.ultralytics.com/guides/yolo-data-augmentation)说明 Mosaic 对尺度/小目标有帮助，并建议在训练末期关闭以稳定收敛。
- [SAHI 论文](https://arxiv.org/abs/2202.06934)显示切片训练和推理能提升小目标 AP，但实时端需要多次推理。
- [Object-Aware Domain Generalization](https://arxiv.org/abs/2312.12133)强调变换应保留目标语义，而不是用过强增强破坏目标纹理。
- [AugMix](https://arxiv.org/abs/1912.02781)和[Style Augmentation](https://arxiv.org/abs/1809.05375)支持用多种外观扰动提升未知腐蚀和域偏移鲁棒性。
- [OHEM](https://arxiv.org/abs/1604.03540)与[Focal Loss](https://arxiv.org/abs/1708.02002)说明困难样本比海量容易背景更值得训练关注。
- [Sipeed 自定义 YOLO 文档](https://wiki.sipeed.com/maixpy/doc/zh/vision/customize_model_yolov8.html)确认 MaixCAM 可部署 YOLOv8/YOLO11；[模型转换文档](https://wiki.sipeed.com/maixpy/doc/zh/ai_model_converter/maixcam.html)要求转换为 INT8 cvimodel，并保持训练与 MUD 预处理一致。

## 数据策略

1. 用户提供的 PPT 测试图片只进入 `camera_holdout`，不进入训练。
2. 训练正样本来自其他来源，并先做感知哈希去重，排除与 holdout 近似的图片。
3. 使用 MaixCam 实拍非 PPT 正样本，覆盖：亮/暗、低饱和、偏角、远近、轻微失焦、运动模糊和局部遮挡。
4. 实拍无目标帧作为困难负样本，包括屏幕文字、激光红点、粉色物体、红色物体、反光和复杂墙面。
5. 所有增强在按来源分割 train/val/test 之后生成，禁止同一原图的不同增强跨 split。

## 训练候选

- 候选 A：当前 YOLOv8n，从最佳旧权重低学习率真实域微调。
- 候选 B：YOLO11n，从官方预训练权重训练，使用完全相同的数据和增强。
- 输入保持 `640x480`，部署仍为单次全帧推理。
- 光度增强覆盖 gamma、曝光、对比度、饱和度、白平衡、噪声、JPEG 压缩、失焦和运动模糊；保留至少 30% 未增强真实帧。
- 几何增强覆盖小角度旋转、透视、平移和尺度变化；不使用会严重破坏卵粒结构的强 MixUp。

## 验收标准

最终以未参与训练的 MaixCam 实拍 holdout 为准：

- 正样本帧召回率不低于 90%，目标级 `Recall@IoU0.5` 不低于 90%。
- 困难负样本误检率不高于 1%，并单独报告每 1000 帧误检数。
- 浅色、暗光、偏角、远距离四个子集分别报告，不允许只给总体平均值。
- 连续视频中稳定检测帧比例不低于 95%，短漏检由跟踪器桥接，但模型召回单独统计。
- FP32、ONNX、INT8 cvimodel 使用同一批图比较，防止量化后召回退化被隐藏。
- MaixCam 实机保持单次全帧推理，目标帧率不低于 15 FPS。
