# 福寿螺卵识别与云台系统架构

## 1. 运行链路

```text
GC4653 相机 320x224/60 FPS
        |
        +--> YOLO11 INT8（每帧推理）--> 几何/粉色复核 --> 多目标跟踪
        |                                                |
        |                                                +--> 手机点选与锁定可信度门
        |                                                          |
        |                                    +---------------------+-------------------+
        |                                    |                                         |
        |                              稳定锁定                                  锁定不稳定
        |                                    |                                         |
        |                       30 Hz 视觉误差控制                         一次保守角度计划
        |                                    |                                         |
        |                       50 Hz 双轴直线小步插值                       冻结并手动微调
        |                                    |
        +--> 红色瞄准点检测 --------------> 闭环参考点
        |
        +--> 最新帧 JPEG 流 --> 手机横屏网页
```

## 2. 并发边界

- 主视觉循环：相机读取、YOLO、颜色复核、目标状态机、遥测和 JPEG 编码。
- 云台轨迹线程：独立 50 Hz 输出双轴同步轨迹；视觉更新频率变化不会直接形成 PWM 台阶。
- JPEG 发送线程：只保留最新一帧，慢客户端不会积压旧画面。
- 网页控制线程：处理点选、1° 微调、居中、保持、模式切换和急停；共享状态由锁保护。

## 3. 人工点选状态机

| 状态 | 进入条件 | 云台动作 | 退出条件 |
| --- | --- | --- | --- |
| `select` | 默认或取消选择 | 不跟踪 | 点击有效绿色框 |
| `confirming` | 点击有效目标 | 原地保持 | 连续 4 次一致观测，或累计 8 次仍不稳定 |
| `stable` | 同 ID、中心和尺寸稳定 | 持续闭环跟踪 | 到位转手动，或持续丢失转保守完成 |
| `approach_hold` | 初始锁定失败 | 只走首次保守角度计划 | 到达后保持手动模式 |
| `manual` | 到位、丢失、方向键或居中 | 50 Hz 平滑移动到指定角度 | 用户重新点选或切换模式 |
| `hold` | 保持或急停 | 冻结当前位置 | 用户明确解除 |

人工点选后只接受原始 `track_id`；邻近目标、重新出现的其他框和自动模式候选均不能接管该锁。程序退出时原地停止并关闭 PWM，不自动回中。

## 4. 安全边界

- 舵机软件限幅：左右 `60..120°`，俯仰 `80..120°`。
- 辅助红色瞄准灯只有视野内存在稳定有效卵团时才允许开启；连续约 2 秒无有效目标后关闭。
- 网页“开启瞄准灯”不能绕过视觉安全门；急停立即关闭辅助灯并冻结云台。
- 高功率消杀激光不由本程序自动触发，保留人工确认。
- 单帧检测、预测过期、红点丢失、程序退出均不得触发突变运动。

## 5. 性能设计

- 模型输入固定为 `320x224`，YOLO 每个主循环帧刷新一次；卡尔曼只桥接最多 3 个连续漏检帧。
- `loop_fps`、`detect_hz`、`stream_fps` 分开统计，不能把相机标称帧率当作识别帧率。
- JPEG 编码仍位于主视觉循环，这是当前网页流的主要可测开销；发送已经异步并采用最新帧覆盖。
- 屏幕可通过 `headless` 标志关闭，手机网页模式下减少显示开销。

## 6. 当前未闭环事项

1. 当前部署模型为 YOLO11n `v26_union`；后续候选必须同时超过其独立召回和困难负样本指标才可替换。
2. 新状态机已通过主机回归，但仍需在 MaixCAM、真实舵机负载和手机网络下记录轨迹验证。
3. 网页 JPEG 的实际编码耗时需要用设备 `PROF` 数据复核；达到瓶颈时再评估 RTSP，而不是用降低检测频率掩盖问题。
4. 红点闭环依赖工作距离和机械安装关系，安装变化后必须重新标定固定参考点。
